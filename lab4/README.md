# ЛР4. Базовые растровые алгоритмы (TypeScript)
```
npm install
npm run dev      # локально
npm run build    # статический сайт в dist/ -> выложить на GitHub Pages / Netlify / Vercel
```
Модули: `RasterEngine.ts` (алгоритмы, IRasterTarget.setPixel), `VirtualGrid.ts` (виртуальный растр),
`GridPainter.ts` (отрисовка клеток/сетки/осей), `Benchmark.ts` + `Chart.ts` (стресс-тест и графики).
