# Лабораторная работа 3 — вариант 10
React + TypeScript. Без сервера, UI-библиотек и библиотечных фильтров.

## Запуск
Установите актуальную LTS-версию Node.js. В папке проекта выполните:
```
npm install
npm run dev
```
Откройте адрес из терминала. Не открывайте index.html двойным щелчком.
Проверка типов и сборка: `npm run build`. Просмотр сборки: `npm run preview`.
Для сдачи опубликуйте содержимое dist на статическом хостинге. Проект пока не опубликован.

## Возможности
- Медианный, минимальный, максимальный фильтры; окна 3x3, 5x5, 7x7.
- Обработка краев Clamp и Reflect (с повтором крайнего пикселя).
- Глобальная бинаризация: Оцу и итеративный порог.
- Адаптивный порог mean(window)-C с интегральным изображением.
- Загрузка, до/после, сохранение PNG, шесть тестовых изображений.
- Один Web Worker для отзывчивости интерфейса.
Все методы применяются к исходнику. Цветовые каналы фильтруются независимо.
Canvas только читает/выводит RGBA; математическая обработка выполняется вручную.

## Файлы
App.tsx — интерфейс; pixels.ts — буфер и края; algorithms.ts — математика;
worker.ts — фоновое вычисление. public/tests — тестовая база.

## Проверка
1. Шум «соль и перец»: медианный фильтр 3x3, затем 5x5.
2. Белый импульсный шум: минимальный фильтр 3x3.
3. Черный импульсный шум: максимальный фильтр 3x3.
4. Маленький объект и три уровня: сравнить Оцу и итеративный метод,
   записать пороги и оценить выделение интересующего объекта.
5. Неравномерный фон: сравнить глобальные методы с адаптивным (окно 31, C=10).
6. Загрузить собственные фотографии и проверить сохранение результата.

Минимальный фильтр расширяет темные области, максимальный — светлые.
Медианный фильтр может удалять мелкие детали при большом окне.
Синтетические тесты нужны для демонстрации, а не доказательства универсального качества.

## Ограничения
В задании адаптивный алгоритм должен соответствовать лекции. Лекции нет,
поэтому реализовано локальное среднее минус C: соответствие нужно проверить.
Пункты 10А по Оцу и SAT учтены; для нелинейных фильтров тоже добавлены Clamp/Reflect.
Один worker не является многопоточной фильтрацией для максимальной оценки.
Гистограмм и результатов реальных запусков пока нет. Сборка и браузерная проверка
в среде создания архива не выполнялись. В PDF описана реализация и порядок проверки,
но экспериментальные результаты не выдуманы.
